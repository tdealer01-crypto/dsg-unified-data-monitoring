DSG Unified Data Monitoring System

Complete monitoring architecture for schema consistency and data sync health across unified Supabase

System Architecture Overview

📊 Schema Consistency

  • Migration version alignment
  • Table definition validation
  • Index coverage analysis
  • Function signature checks
  • SHA-256 schema hashing

📈 Data Sync Health

  • 8 critical table monitoring
  • Row count tracking
  • Modification timestamps
  • State hash comparison
  • Health score (0-100)

🔍 Divergence Detection

  • Orphaned records
  • Unscoped org_id fields
  • Missing required fields
  • RLS policy violations
  • FK constraint checks

🔐 Cross-Repo Validation

  • Service role access
  • Org_id boundary enforcement
  • Table permissions
  • Visibility scope checks
  • Auth user isolation

API Request/Response Flow

Data Sync Verification Workflow

1
Schema Consistency Check

Verify all repositories use compatible schema versions and migrations are properly applied

2
Monitor Critical Tables

Check row counts, modification timestamps, and data distribution across all 8 critical tables

3
Detect Divergences

Identify orphaned records, unscoped fields, missing required fields, and RLS violations

4
Validate Cross-Repo Access

Confirm service roles work correctly and org_id isolation is enforced across all repositories

5
Calculate Health Score

Generate score (0-100), identify issues, and provide actionable recommendations
