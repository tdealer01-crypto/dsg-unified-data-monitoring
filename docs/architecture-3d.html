Post-deploy decision contract

BLOCK

Health/readiness failure, invalid binding/evidence, or protected metric regression. Monitoring emits ROLLBACK_RECOMMENDED; it does not execute rollback.

REVIEW

Evidence is insufficient or the deployment is neutral. Current baseline remains authoritative.

PASS

At least one metric improves, no protected metric regresses, and canary evidence is sufficient. Returns nextBaselineEligible=true.
